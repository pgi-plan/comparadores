# University Ranking Data Visualizer

This repository contains interactive dashboards for visualizing and comparing university rankings using data from QS, THE, RUF, RUR, and Scopus. All dashboards are generated client-side and automatically updated from the CSV files stored in the repository.

## 📁 Repository Structure

* 📂 `qs_world/` — Dashboard + QS World datasets
* 📂 `qs_sustainability/` — Dashboard + QS Sustainability datasets
* 📂 `qs_latin_america/` — Dashboard + QS Latin America datasets
* 📂 `times_higher_education/` — Dashboard + THE datasets
* 📂 `times_higher_education_latin_america/` — Dashboard + THE Latin America datasets
* 📂 `the_impact_rankings/` — Dashboard + THE Impact Rankings datasets
* 📂 `rur/` — Dashboard + RUR datasets
* 📂 `ranking_universitario_folha/` — Dashboard + RUF datasets
* 📂 `cursos_ruf/` — Dashboard + RUF undergraduate program datasets
* 📂 `scopus_sdgs_data/` — Dashboard + Scopus SDG datasets
